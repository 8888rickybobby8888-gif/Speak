# Speak libraries

Well-known Python libraries, re-described in plain English with no abbreviations.

```
use numpy
use micromelon as robot

scores = numpy.array([4, 8, 15, 16, 23, 42])
print numpy.standard_deviation(scores)
```

- `use NAME` loads the **Speak version** of a library if there is one (listed below). For any other installed Python library it gives you the ordinary library, so `use scipy` works too.
- `use NAME as OTHER` picks the name you will type, for example `use micromelon as robot`.
- `use a, b, c` loads several at once.
- Every Speak library has `.raw`, the original Python library, for anything not covered: `numpy.raw.linalg.norm(values)`.
- `NAME.list_functions()` prints everything a library offers, with descriptions.
- The ordinary Python way (`import numpy as np`) still works and can be mixed with `use`.
- Libraries that are not part of Python must be installed first (for example `pip install numpy`).
- Positions that these libraries return or accept count from **1**, matching `item N of`.

Contents: [numpy](#numpy), [pandas](#pandas), [matplotlib](#matplotlib), [micromelon](#micromelon), [math](#math), [random](#random), [time](#time).

## micromelon

**micromelon: Micromelon rovers**

Install: `pip install micromelon`

Micromelon rover control in plain English (needs: pip install micromelon).

Typical use, with the Micromelon Robot Simulator running: use micromelon micromelon.connect_to_simulator() micromelon.drive_forward_distance(30) micromelon.turn_right(90) print micromelon.distance_ahead() micromelon.disconnect()

Speeds are in centimetres per second (-30 to 30), distances in centimetres, angles in degrees. Colours can be a name such as "red" or a list of three numbers [red, green, blue] from 0 to 255. Notes can be a name such as "C4" or "F#5" (or "Bb3"), or a frequency in hertz. Sensors can be "left", "middle" or "right"; axes can be "x", "y" or "z". The original library is available as `raw`.

### Connecting

| Write | Does |
| --- | --- |
| `micromelon.connect_to_simulator(address='127.0.0.1', port=9000)` | Connects to the Micromelon Robot Simulator (or any rover on the network) and starts it. |
| `micromelon.connect_by_bluetooth(robot_number)` | Connects to a real rover over Bluetooth using the number on its label, and starts it. |
| `micromelon.connect_by_serial(port='/dev/ttyS0')` | Connects to a rover attached to a Raspberry Pi serial port, and starts it. |
| `micromelon.disconnect()` | Stops the rover and disconnects from it. |
| `micromelon.is_connected()` | True if the program is connected to a rover. |

### Driving

| Write | Does |
| --- | --- |
| `micromelon.drive(left_speed, right_speed=None, seconds=0)` | Sets the speed of the left and right wheels. With seconds, drives that long then stops. |
| `micromelon.drive_forward(speed=15, seconds=0)` | Drives forward at this speed. With seconds, drives that long then stops. |
| `micromelon.drive_backward(speed=15, seconds=0)` | Drives backward at this speed. With seconds, drives that long then stops. |
| `micromelon.drive_forward_distance(centimetres, speed=15)` | Drives forward this far, then stops. The program waits until it arrives. |
| `micromelon.drive_backward_distance(centimetres, speed=15)` | Drives backward this far, then stops. The program waits until it arrives. |
| `micromelon.drive_each_side_distance(left_centimetres, left_speed, right_centimetres, right_speed)` | Drives each side a different distance at a different speed, which makes a curve. |
| `micromelon.turn_left(degrees, speed=15)` | Turns on the spot to the left by this many degrees. |
| `micromelon.turn_right(degrees, speed=15)` | Turns on the spot to the right by this many degrees. |
| `micromelon.stop_moving()` | Stops both wheels. |

### Sensors

| Write | Does |
| --- | --- |
| `micromelon.distance_ahead()` | The distance in centimetres to the nearest thing in front, from the ultrasonic sensor. |

| `micromelon.both_distances()` | The left and right infrared distances as a list [left, right]. |
| `micromelon.colour_hue(sensor='middle')` | The hue (0 to 359) that a colour sensor sees. |
| `micromelon.colour_values(sensor='middle')` | Everything a colour sensor reads: its colour amounts and brightness. |
| `micromelon.sees_colour(colour, sensor='middle', tolerance=20)` | True if a colour sensor sees this colour (a name or [red, green, blue]). |
| `micromelon.battery_percentage()` | How full the battery is, as a percentage. |
| `micromelon.battery_voltage()` | The battery voltage in volts. |
| `micromelon.is_upside_down()` | True if the rover has flipped over. |
| `micromelon.is_upright()` | True if the rover is the right way up. |
| `micromelon.acceleration(axis=None)` | How hard the rover is accelerating, in g. Give an axis ("x", "y" or "z") or get all three. |
| `micromelon.turning_speed(axis=None)` | How fast the rover is turning, in degrees per second. Give an axis or get all three. |

### Lights, sounds, screen, servos

| Write | Does |
| --- | --- |
| `micromelon.colour(name)` | The [red, green, blue] numbers for a named colour, such as "orange". |

| `micromelon.play_note(note, seconds=None)` | Plays a note (a name like "C4" or a frequency in hertz). With seconds, waits that long. |
| `micromelon.play_tune(name)` | Plays a built-in tune: "up" or "down". |
| `micromelon.silence()` | Stops any sound. |
| `micromelon.show_on_screen(text, label=None)` | Shows text on the rover's screen (up to 15 letters). |
| `micromelon.robot_name()` | The name of the connected rover. |

| `micromelon.move_right_servo(degrees)` | Turns the right servo to an angle from -90 to 90 degrees. |
| `micromelon.move_both_servos(left_degrees, right_degrees)` | Turns both servos to angles from -90 to 90 degrees. |
